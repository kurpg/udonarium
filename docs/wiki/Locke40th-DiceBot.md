# 超人ロック40th ダイスボット 開発ガイド

既存の「超人ロック」ダイスボットをコピーして作った「超人ロック40th」ダイスボットに、機能を追加していくための手順書です。
人が作業する場合も、Claude（Claude Code）に作業させる場合も、このページを基準にしてください。

## 現在の状態

- 「超人ロック40th」はダイスボット一覧に表示され、選択できます。
- **中身は既存の「超人ロック」と同じ**です（ファイルをコピーして名前だけ変えた状態）。
- 40th 版のルールに合わせた表・コマンドの変更はこれから行います。

## よくある作業

### 表（チャート）の中身を変える

`Locke40thDiceTable.ts` の `TABLE_*` 定数を書き換えます。書式は BCDice の `UserDefinedTable` 形式です。

```
表のタイトル
2D6
2:出目2の結果
3:出目3の結果
...
12:出目12の結果
```

- 1行目: 表示名、2行目: 振るダイス（`2D6`、`1D6` など）、3行目以降: `出目:結果`
- 結果の文章の中で改行しないこと（1行 = 1つの出目）

### 新しい表コマンドを追加する（例: `NEW`）

以下の **4か所すべて** を変更します。1つでも漏れるとコマンドが反応しません。

1. `Locke40thDiceTable.ts` に `const TABLE_NEW = \`...\`` を追加
2. `Locke40thDiceTable.ts` の `tableFromCommand` 内の対応表に `"NEW": TABLE_NEW,` を追加
3. `Locke40thDice.ts` の `COMMAND_PATTERN` の `|` 区切りに `NEW` を追加
4. `Locke40thDice.ts` の `TABLE_PATTERN` の `|` 区切りに `NEW` を追加
5. （推奨）`HELP_MESSAGE` に説明を追加

注意: 正規表現は前から順に一致を試します。`SHIP` と `SHIP_BM` のように、**一方がもう一方の先頭と同じコマンドは、長い方を先に書いて**ください。

### 表以外の計算を変える

`Locke40thDice.ts` の以下のメソッドを編集します。

- `rollDamage` … `DMGn` のダメージ表（`damageRateTable`）
- `rollWeapon` … `nRG` / `nBL` / `nBZ` / `nBC` の火力（`WEAPONS`）
- `rollJail` … `JAILn` の逮捕チェック

計算型の新コマンドを追加する場合は、既存の `DMG` / `JAIL` を真似て
「`*_PATTERN` 定義 → コンストラクタで match → `diceText` 設定 → `eval()` で分岐 → `rollXxx()` 実装」の流れで追加し、`COMMAND_PATTERN` にも追加します。

## 作業の流れ（ブランチ・確認）

1. `kurpg`（デフォルトブランチ）から作業ブランチを作る（例: `feature/locke40th-trap-table`）
2. 上記の手順で変更
3. ビルド確認: `npm ci`（初回のみ） → `npm run build`
   - CSS や bundle の `exceeded maximum budget` 警告は以前から出ているもので、無視して構いません
   - `Error:` が出たら失敗です
4. 動作確認: `npm start` で起動し、http://localhost:4200 を開く
   - チャットのダイスボット選択で「超人ロック40th」を選ぶ
   - 変更したコマンドを振って結果を確認する
   - 「超人ロック」（既存版）も今まで通り動くことを確認する
5. コミットして push し、Pull Request を作る

## Claude に作業してもらう場合

Claude Code はリポジトリ直下の `CLAUDE.md` を自動で読み、そこからこのページを参照します。
依頼するときは **何をどう変えるか（ルールの中身）を具体的に** 書いてください。ルールブックの内容は Claude には分かりません。

依頼文の例:

```
超人ロック40thのダイスボットで、トラップ1（T1）の表を以下の内容に差し替えてください。
2:〇〇
3:〇〇
...
12:〇〇
docs/wiki/Locke40th-DiceBot.md の手順に従い、ビルド確認してから push してください。
```

```
超人ロック40thに新しい表コマンド「EVT」（イベント表、2D6）を追加してください。
内容は以下です。
...
ヘルプにも「EVT イベント表」と追加してください。
```

```
超人ロック40thの DMG コマンドのダメージ表を以下に変更してください。
（表を貼る）
```

依頼のコツ:

- 1回の依頼は1つのテーマ（1つの表、1つのコマンド）にすると確認しやすい
- 表は出目と結果をすべて書く（「前と同じ」などは対象を明記する）
- 既存の「超人ロック」は変更しないこと、を必要に応じて念押しする
